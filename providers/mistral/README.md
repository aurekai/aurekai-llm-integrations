# Mistral Provider Adapter

Package: `@aurekai/mistral`

## Surfaces

1. Tool calling adapter
2. Remote MCP server bridge
3. Provider workflow template
4. Batch and eval connector
5. Semantic cache and model-memory hook

## Primary Capability

- Mistral agent connector + function calling

## Example Commands

```bash
akai provider mistral tools:print
akai provider mistral run --proof --semantic-cache
```
