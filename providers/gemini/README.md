# Gemini Provider Adapter

Package: `@aurekai/gemini`

## Surfaces

1. Tool calling adapter
2. Remote MCP server bridge
3. Provider workflow template
4. Batch and eval connector
5. Semantic cache and model-memory hook

## Primary Capability

- Gemini function declarations + context cache bridge

## Example Commands

```bash
akai provider gemini tools:print
akai provider gemini run --proof --semantic-cache
```
