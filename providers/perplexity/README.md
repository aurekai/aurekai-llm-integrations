# Perplexity Provider Adapter

Package: `@aurekai/perplexity`

## Surfaces

1. Tool calling adapter
2. Remote MCP server bridge
3. Provider workflow template
4. Batch and eval connector
5. Semantic cache and model-memory hook

## Primary Capability

- Perplexity citations to Aurekai proof bundles

## Example Commands

```bash
akai provider perplexity tools:print
akai provider perplexity run --proof --semantic-cache
```
