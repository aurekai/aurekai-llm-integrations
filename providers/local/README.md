# Local Provider Adapter

Package: `@aurekai/local`

## Surfaces

1. Tool calling adapter
2. Remote MCP server bridge
3. Provider workflow template
4. Batch and eval connector
5. Semantic cache and model-memory hook

## Primary Capability

- Local Llama stacks and runtime tool bridge

## Example Commands

```bash
akai provider local tools:print
akai provider local run --proof --semantic-cache
```
