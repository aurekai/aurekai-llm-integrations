# Groq Provider Adapter

Package: `@aurekai/groq`

## Surfaces

1. Tool calling adapter
2. Remote MCP server bridge
3. Provider workflow template
4. Batch and eval connector
5. Semantic cache and model-memory hook

## Primary Capability

- Groq low-latency tool calling + remote MCP

## Example Commands

```bash
akai provider groq tools:print
akai provider groq run --proof --semantic-cache
```
